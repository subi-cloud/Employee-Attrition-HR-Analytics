# Dataset

This project uses the **IBM HR Analytics Employee Attrition & Performance** practice dataset.

The dataset contains employee-related attributes used to analyze factors associated with employee attrition.

## Dataset Source

The dataset was obtained from Kaggle for educational and analytical purposes.

To run this project locally, download the dataset from its original source and place the CSV file in this folder with the following filename:

`WA_Fn-UseC_-HR-Employee-Attrition.csv`

The expected project structure is:

```text
data/
└── WA_Fn-UseC_-HR-Employee-Attrition.csv
